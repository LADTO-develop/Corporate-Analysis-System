# Macro Raw Inputs

CAS-internal macro inputs used for reproducible Stage 1 feature generation.

## Files

- `ECOS_Macro_Processed.csv`: copied from the project-level
  `02_Processed_Data/ECOS_Macro_Processed.csv` source so candidate artifact
  generation does not depend on an external folder link.

`market_spread_diff` is computed as the year-over-year difference of
`market_spread` from this file.
